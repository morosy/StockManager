# StockManager

StockManager は、ボード単位で在庫管理できる Android アプリです。
Jetpack Compose で UI を構築し、Room でローカル永続化しています。

初回起動時は `ボード1` と `アイテム1` が作成され、アプリ内チュートリアルで基本操作を案内します。

現在のアプリバージョンは `1.1.8` です。

## 主な機能

- ボード管理
  - ボードの追加・削除・並び替え・名前変更
  - ボードがない場合の空状態表示
- マグネット（アイテム）管理
  - 追加・削除・3 状態の切り替え（白 / 黄 / 赤）
  - 名前入力の最大文字数制限（24 文字）
- 一覧機能
  - 在庫 / 欠品フィルタ
  - ソート（古い順 / 新しい順 / 名前順 / 名前逆順 / 在庫順 / 欠品順）
  - 検索
  - 複数ボード横断の欠品リスト表示
- データ連携
  - JSON / CSV エクスポート
  - JSON / CSV インポート
  - メニューからの全データ削除
- ガイド
  - 初回チュートリアル
  - チュートリアル進捗表示
  - メニューの `使い方` からチュートリアルを再表示
- 情報画面
  - About（バージョン / コピーライト）
  - OSS ライセンス
  - 利用規約
  - プライバシーポリシー

## 現在の仕様メモ

- 初期状態では `ボード1` と `アイテム1` が作成されます
- ボードをすべて削除した場合はホームに `ボートがありません` / `ボードを追加してください` を表示します
- メニューの `データを削除` は 2 段階確認です
- 2 回目の確認では `delete` と入力したときだけ削除が実行されます
- データ削除を実行すると、保存中のボード・アイテム・設定を全消去してアプリを終了します
- 次回起動時は初期データが再生成され、チュートリアルから開始します
- `在庫順` は `白 -> 黄 -> 赤`
- `欠品順` は `赤 -> 黄 -> 白`
- 画面下部には `編集 / 欠品リストを表示 / 追加` の 3 つの FAB を表示します
- `欠品リストを表示` では、全ボード選択を初期状態として黄色・赤色アイテムのみを集約表示します
- 欠品リストの結果一覧は `黄色 -> 赤色` を優先し、その中で現在のソートモードを適用します
- ボード選択画面は外タップで閉じられます
- 欠品リスト結果画面は外タップで閉じません
- 欠品リスト結果画面では、カードをタップしてドラフト状態のステータス変更ができます
- 白に変わったアイテムも保存前は欠品リスト内に残り、`保存して閉じる` を押した時点でのみ実データへ反映されます
- 変更がある状態で `X` や戻る操作を行うと、変更破棄の確認ダイアログが表示されます
- ソートボタン右側の矢印で `古い順 / 新しい順` `名前順 / 名前逆順` `在庫順 / 欠品順` を切り替えられます
- CSV は旧形式との互換を保ちながら `status` 列にも対応しています
- `使い方` のチュートリアルは初回起動時に自動表示され、あとからメニューの `使い方` で再表示できます
- チュートリアルは開始時のボード有無に応じて 11 枚または 12 枚構成に切り替わります
- ただし、ボードが 0 件の状態でチュートリアルを開いた場合は、`ボードを追加する` ステップでボードを 1 つ作成するまで先へ進めません
- チュートリアル最終ステップでは `スキップ` は表示されません
- 検索バーの `閉じる` を押すと、検索 UI を閉じるだけでなく検索条件も解除されます
